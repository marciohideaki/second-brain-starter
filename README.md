# second-brain-starter

> A starter kit to build your own AI-powered second brain using Claude Code — that actually remembers what you taught it, session after session.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![CI](https://github.com/marciohideaki/second-brain-starter/actions/workflows/ci.yml/badge.svg)](https://github.com/marciohideaki/second-brain-starter/actions/workflows/ci.yml)
[![Claude Code](https://img.shields.io/badge/Claude%20Code-ready-blue)](https://docs.anthropic.com/claude-code)

**Work in progress.** The full documentation, skills, hooks, adapters, visuals, and demos land progressively through the feature branches merged into `develop`. First release will be tagged as `v0.1.0` once the release branch is merged into `main`.

## Project metadata

- [LICENSE](LICENSE) — MIT
- [CHANGELOG.md](CHANGELOG.md) — release history
- [CONTRIBUTING.md](CONTRIBUTING.md) — how to contribute (populated by a later feature branch)
- `.github/` — issue templates, PR template, CI workflow

## Branches

- `main` — stable, release-tagged.
- `develop` — integration branch where features land via PR.
- `feature/*` — one feature per branch, merged into `develop` through reviewed PRs.
- `release/*` — release cuts, merged into `main` with a version tag.

See the [CHANGELOG](CHANGELOG.md) for what is included in each release.
